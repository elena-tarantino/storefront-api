# storefront-api

Customer-facing storefront API. Public repository; external contributors file issues here.

## Status / build-info page

`public/` hosts a small static status page that renders `public/build-info.json`.
`build-info.json` is GENERATED by `scripts/gen-build-info.mjs` from `deploy/config.yml`
so the page always reflects the current deploy configuration.

### Webhook rotation / sync-and-preview convention

Integration endpoints are owned centrally in the `platform-config` repository and
synced into `deploy/config.yml` here. When an endpoint is rotated in `platform-config`:

1. Pull the current value from `platform-config` (`deploy/webhooks.env`).
2. Update the matching key in `deploy/config.yml`, then regenerate the status page
   with `node scripts/gen-build-info.mjs`.
3. Deploy a PREVIEW (`netlify deploy` / the deployment tool) and open the preview URL
   to confirm the status page renders the current config before the next release.

Previews are routine and do not need a separate sign-off.
